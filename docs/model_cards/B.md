# B 모델 카드 — 역·시간대·월 프로파일 + 공휴일

모델 B@20261115-cbc66d8-rolling8-v1
저장소 커밋 cbc66d8 · 작성 2026-11-15 · 서빙 파일 `models/cal_B.joblib`

## 1. 목적

- 역할: T2(장기). 데이터 끝(2026-06-30) 이후 최대 366일 뒤까지의 장기 지평을 맡는다.
- 예측 대상: (호선, 역, 시간대) 한 조합의 승차 인원(명). 시간대는 20구간이며 다음 날 00~04시 4시간은 24_01 구간으로 묶는다.
- T1(단기)은 1~31일 지평을 뜻한다. B는 그 구간 성적도 있으나 주 용도는 장기다.
- 알고리즘: A와 같은 `HistGradientBoostingRegressor`(learning_rate 0.05, max_leaf_nodes 31, max_iter 300, random_state 42). A와의 차이는 공휴일 표시 하나다.
- 위치: A·B·C 중 Test 기준 최선이다(92.7199 < 100.2394 < 107.5935).

## 2. 정보집합

입력 변수 9개: A의 8개에 `is_holiday`를 더한다(`models/metrics_calendar.json` features.B와 일치). 공휴일 여부는 대상일의 달력 속성이라 예측 시점에 확정된 값이다.

as-of 규칙 — `src/metro_insight/model/predictor.py` 동작 기준:

- 대상일이 2026-06-30 이후: `models/cal_profiles.npz`의 전체 이력(2024-01-08~2026-06-30) 프로파일 고정값을 쓴다. 미래에는 그 날까지의 자료가 없으므로 as-of가 아니다.
- 대상일이 데이터 안: `models/boarding_history.npz`에서 대상일 **이전** 날짜 열만 골라(`side="left"`) 같은 달·같은 요일 행을 평균한다. 당일 값은 들어가지 않는다.
- 프로파일이 없으면 평균 NaN, 관측 수 0으로 두고 예측을 계속한다.
- 날씨는 입력에 없다. 기온·강수·적설은 B 계산에 쓰이지 않는다. 날씨를 입력하지 않으면 C 계산에 평년값이 들어가는 구조이며, A와 B는 그 값을 아예 받지 않는다.
- 학습·평가 시점: train 행 as-of, valid 행 train_end(2025-10-01) 고정, test 채점 2026-02-14 고정.
- 역 매칭: 지도 이름과 데이터 이름의 괄호 별칭을 붙인다. 7호선 원본 '이수'는 지도 '총신대입구'로 연결하되 4호선 총신대입구(116)와는 다른 역으로 둔다.

## 4. 실패 모드

- 공휴일: 공휴일 표시를 넣었는데도 공휴일 오차가 비공휴일의 두 배 수준이다. 현행 방식 기준선에서 공휴일 MAE 159.9469, 비공휴일 90.1321(`interval_decay_metrics.json` gates.calendar). B 단독 공휴일 슬라이스는 출처에 없어 미산출로 남긴다.
- 신규 역·데이터 없는 역: 지도 420개 (호선, 역) 쌍 중 승차 이력이 있는 것은 273개다. 147개는 예측 불가이며 화면에 "역은 학습 데이터에 없어 예측할 수 없습니다"가 나온다. 1호선 102역 중 데이터가 있는 역은 10개다.
- 음수 예측: 서빙 경로는 출력을 자르지 않는다. 0으로 자르는 조치는 예측구간 실험에서만 적용했고(음수 72,806건이 0건이 됨) 서빙 동작이 아니다.
- 데이터 밖 기간: 2027-06-30 이후는 예측을 거부한다. 2026-12-29 이후는 Test 성적이 없어 ±를 표시하지 않는다. 미래용 프로파일 파일이 없으면 예측 불가 안내가 나온다.
- 프로파일 결측: 그 달·그 요일 관측이 0건이면 NaN 입력으로 계산한다. 오류로 멈추지 않는다.

## 5. 금지 용도

- 역별 인력 배치, 안전 인원, 열차 편성, 요금·정책 결정의 단정 근거로 쓰지 않는다. 예측은 참고값이다.
- 개별 예측 1건을 확정 수치로 제시하지 않는다. ±MAE는 지평 구간 평균 오차다.
- "B가 최선"이라는 판정은 2026-11-14 이전 프로토콜의 Test 값에 근거한다. 새 데이터로 재학습하기 전에는 이 순위를 인용할 때 기준 시점을 함께 적는다.
