# D 모델 카드 — 과거 이용량 시계열 + 달력·날씨 (LSTM)

모델 D@20261115-cbc66d8-rolling8-v1
저장소 커밋 cbc66d8 · 작성 2026-11-15 · 서빙 파일 `models/sequence_D.pt`

## 1. 목적

- 역할: T1(단기). 대상일 하루 앞을 맞히는 단기 예측을 맡는다(T2 장기는 A·B·C 담당).
- 예측 대상: (호선, 역, 시간대) 한 조합의 승차 인원(명). 시간대는 20구간이며 다음 날 00~04시 4시간은 24_01 구간으로 묶는다.
- 구조: LSTM(Long Short-Term Memory) 한 층, 은닉 상태 64차원, 드롭아웃 0.1, SmoothL1Loss 손실, Adam 1e-3, 배치 512, 시드 42. 창 길이 14일.
- 위치: A·B·C와 정보집합이 다르다. D는 직전 14일 실측을 입력으로 쓰고 A·B·C는 쓰지 않는다. 그래서 성적을 같은 줄로 줄 세우지 않는다.

## 2. 정보집합

`src/metro_insight/model/sequence_predictor.py`와 `src/metro_insight/model/predictor.py` 동작 기준.

- 시계열: 같은 역·시간대의 **직전 14일** 실측 승차 인원. 정규화는 그 역·시간대 학습 평균으로 나눈 값이다.
- 창의 보조 입력: 창 14일 각각의 요일, 공휴일 여부, 기온, 강수, 적설(그 시점 실측).
- 대상일 입력: 요일, 공휴일, 기온, 강수, 적설, 그리고 프로파일 4종(월 프로파일 평균·관측 수, 요일 프로파일 평균·관측 수).
- 임베딩: 역, 호선, 시간대.

as-of(기준 시점) 규칙:

- 창은 대상일 **이전** 14일이다(대상일 열 제외). 당일 값은 어떤 경로로도 들어가지 않는다.
- 창 14일에 결측이 하나라도 있으면 예측을 만들지 않고 그 모델 키를 비운다(오류 메시지로 남긴다).
- 대상일의 요일·공휴일은 예측 시점에 확정된 달력 정보다. 대상일 날씨는 앱에 입력된 값이며, 입력이 없으면 월별 평년 기온과 "안 옴"으로 채운다.
- 프로파일 4종은 A·B·C와 같은 as-of 규칙으로 계산된 값을 전달받는다(대상일 이전 자료만, 데이터 안 날짜 기준).
- 예측 가능 조건: 체크포인트에 기록된 날짜 범위 안이면서 14일 창이 확보된 날. 실제 범위는 2024-01-22 ~ 2026-06-30이다. 오늘·미래는 14일 창이 없어 D가 나오지 않는다.
- 모델 파일·torch·이력 중 하나라도 없으면 D 키만 빠지고 A·B·C는 계속 동작한다.

## 4. 실패 모드

- 데이터 밖 기간: 오늘·미래는 직전 14일 실측이 없어 D를 계산하지 않는다. 화면에는 "최근 14일 기록 없어 예상 불가"가 나오며 오류가 아니다. A·B·C는 같은 날짜에도 값을 낸다.
- 이력 결측: 14일 창에 빈 시간대가 하나라도 있으면 그 예측은 만들지 않는다.
- 신규 역·데이터 없는 역: 지도 420개 (호선, 역) 쌍 중 승차 이력이 있는 것은 273개다. 147개는 예측할 수 없고, 1호선은 102역 중 10역만 데이터가 있다. 체크포인트에 없는 역 코드도 같은 이유로 제외된다.
- 공휴일: 공휴일 MAE 117.7325로 비공휴일 54.9320의 약 2.1배다. 공휴일 패턴을 충분히 학습하지 못한다.
- 음수 예측: Test 742,560행 중 784건이 음수였고 최소값은 −137.7091이다. 서빙 경로는 이 값을 0으로 자르지 않는다. 0으로 자르는 조치는 예측구간 실험에서만 적용했고(음수 72,806건이 0건이 됨) D 서빙 동작이 아니다.
- 지평 표시 없음: D는 데이터 기간 이후를 예측하지 않으므로 화면의 미래 지평 ±에 D 숫자를 붙이지 않는다(`predictor.py`가 D·E 지평 성적을 합치지 않는 이유).

## 5. 금지 용도

- 역별 인력 배치, 안전 인원, 열차 편성, 요금·정책 결정의 단정 근거로 쓰지 않는다.
- D의 값을 미래 날짜 예측으로 소개하지 않는다. D는 관측이 끝난 날짜(2026-06-30까지)에서만 값이 나온다.
- D와 A·B·C의 성적 차이를 "모델 성능 차이"로만 해석하지 않는다. 최근 14일 실측을 본다는 정보 우위가 포함되어 있고, 그 정보는 미래 날짜에 쓸 수 없다.
- 개별 예측 1건을 확정 수치로 제시하지 않는다.

## 6. 갱신 주기

- 자동 재학습 스케줄은 저장소에 없다. 재학습은 `notebooks/train_sequence.py`를 사람이 실행한다. 지하철 원본과 체크포인트 날짜 축이 맞아야 한다.
- 데이터 갱신: 지하철 원본은 2026-06-30까지이고 2026년 7~12월 원본은 2027-01-29 공개 예정이다(`README.md`). 새 원본으로 재학습하면 예측 가능 범위도 그만큼 늘어난다.
