# C 모델 카드 — 역·시간대·월 프로파일 + 공휴일 + 날씨

모델 C@20261115-cbc66d8-rolling8-v1
저장소 커밋 cbc66d8 · 작성 2026-11-15 · 서빙 파일 `models/cal_C.joblib`

## 1. 목적

- 역할: T2(장기). 데이터 끝(2026-06-30) 이후 최대 366일 뒤까지의 장기 지평을 맡는다.
- 예측 대상: (호선, 역, 시간대) 한 조합의 승차 인원(명). 시간대는 20구간이며 다음 날 00~04시 4시간은 24_01 구간으로 묶는다.
- T1(단기)은 1~31일 지평을 뜻한다. C는 그 구간 성적도 있으나 주 용도는 장기다.
- 알고리즘: A·B와 같은 `HistGradientBoostingRegressor`(learning_rate 0.05, max_leaf_nodes 31, max_iter 300, random_state 42).
- 용도 한정: 날씨 시나리오를 가정해 볼 때만 쓴다. A·B·C 중 Test 기준 최선은 B이며 C는 열세다.

## 2. 정보집합

입력 변수 12개: B의 9개에 `temperature` · `rainfall` · `snowfall`을 더한다(`models/metrics_calendar.json` features.C와 일치).

as-of 규칙 — `src/metro_insight/model/predictor.py` 동작 기준:

- 대상일이 2026-06-30 이후: `models/cal_profiles.npz`의 전체 이력(2024-01-08~2026-06-30) 프로파일 고정값을 쓴다. 미래 시점에는 그 날까지의 자료가 없어 as-of가 아니다.
- 대상일이 데이터 안: `models/boarding_history.npz`에서 대상일 **이전** 날짜 열만 골라 같은 달·같은 요일 행을 평균한다. 당일 값은 구조적으로 배제된다.
- 관측 날씨가 입력되지 않으면 기온은 월별 평년값, 강수·적설은 "안 옴"으로 두고 계산한다. 평년 기온은 1991~2020년 서울 월별 근사값이며 1월 −1.9℃, 8월 26.1℃ 등이다. 즉 날씨를 비우면 C는 "평년 날씨" 가정으로 값을 낸다.
- 강수는 눈을 포함한다. 비·눈은 0/1 값이다.
- 학습·평가 시점: train 행 as-of, valid 행 train_end(2025-10-01) 고정, test 채점 2026-02-14 고정.
- 역 매칭: 지도·데이터 이름의 괄호 별칭을 붙인다. 7호선 '이수'는 지도 '총신대입구'로 연결하되 4호선 총신대입구(116)와 섞지 않는다.

참고: 이 장기 구간에서는 C가 A·B보다 낮다(85.8055 < 87.2143 < 108.5594). Test 1~181일에서는 순위가 뒤집힌다. 지평에 따라 우열이 달라진다는 뜻이며 단일 순위로 요약하지 않는다.

### 확정된 음성 결과 (성능 주장에 쓰지 않는다)

- C는 B보다 열세다. Test MAE 100.2394 대 92.7199로 7.52명 나쁘다. 월별로도 모든 달이 B보다 나쁘고(2월 +1.77, 3월 +1.39, 6월 +13.26), 지평이 길수록 격차가 커진다(1~31일 +0.97에서 92~181일 +12.97).
- 날씨 입력이 성능을 올리지 못한다. 날씨를 평년 기온·무강수로 바꿔 재예측하면 Test MAE가 100.2394에서 95.46으로 **좋아진다**(기온 −4.64, 강수 −0.10, 적설 0.00). 기온을 무작위로 섞어도 −0.91에 그친다. 모델이 기온을 약하게만 쓴다는 진단이다.
- 그래서 C의 날씨 입력은 "예측 정확도를 높이는 정보"로 소개하지 않는다. 날씨 조건을 가정해 보는 용도로만 둔다.
- valid에서는 C가 B보다 4.6명 낮다(C 79.0300 · B 83.7572). 검증 구간에서의 이 우위는 Test에서 재현되지 않았다.

## 4. 실패 모드

- 공휴일: 표시를 넣었는데도 공휴일 오차가 비공휴일의 약 1.8배다(기준선 159.9469 대 90.1321). C 단독 공휴일 슬라이스는 출처에 없어 미산출로 남긴다.
- 날씨 정보 부재·무효: 관측 날씨를 넣지 않으면 평년값으로 계산하므로 실제 한파·폭우일에는 오차가 커진다. 넣어도 위 음성 결과대로 개선이 확인되지 않았다.
- 신규 역·데이터 없는 역: 지도 420개 (호선, 역) 쌍 중 이력이 있는 것은 273개다. 147개는 예측 불가이며 안내 문구가 나온다. 1호선 102역 중 데이터가 있는 역은 10개다.
- 음수 예측: 서빙 경로는 출력을 자르지 않는다. 0으로 자르는 조치는 예측구간 실험에서만 적용했고(음수 72,806건이 0건이 됨) 서빙 동작이 아니다.
- 데이터 밖 기간: 2027-06-30 이후는 예측을 거부한다. 2026-12-29 이후는 Test 성적이 없어 ±를 표시하지 않는다.
- 프로파일 결측: 그 달·그 요일 관측이 0건이면 NaN 입력으로 계산하며 오류로 멈추지 않는다.

## 5. 금지 용도

- 역별 인력 배치, 안전 인원, 열차 편성, 요금·정책 결정의 단정 근거로 쓰지 않는다.
- "날씨를 넣었으니 더 정확하다"는 식의 소개를 금한다. Test 기준으로 C는 B보다 나쁘고, 날씨를 평년값으로 바꾸면 오히려 좋아진다.
- 개별 예측 1건을 확정 수치로 제시하지 않는다. ±MAE는 지평 구간 평균 오차다.
