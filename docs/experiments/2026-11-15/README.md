# 2026-11-15 실험 기록

이 폴더는 2026-11-15 에 실행한 실험의 **판정 근거 원본**을 보관한다. 대용량 산출물(예측 행 단위 파일)은
`models/_exp/` 에 로컬 전용으로 두고 git 에서 제외하며, 여기에는 판정에 필요한 요약·지표·로그만 복사했다.

## 1. 결과 요약

### 다중 지평 예측 (통과)

| 실행 | 통합 평균절대오차(MAE) | 기준선 대비 | 판정 |
|---|---|---|---|
| 기준선 (2026-11-14) | 93.3281 | — | — |
| 지평 밴드 + 그래디언트 부스팅 | 87.1623 | −6.61% | 채택 |
| 지평 밴드 + LightGBM | 86.7308 | −7.07% | 채택 |
| 정보량 일치(matched) | 113.5234 | +21.64% | **반려** |

- 통과 기준: 88.66 (기준선의 −5%). 두 실행 모두 통과, 정보량 일치 방식은 악화되어 반려.
- LightGBM 과 기존 방식의 차이 0.43 은 동률 기준(2.0) 안이다. 우위로 해석하지 않는다.
- 표본 6,983,340행, 기준 시점 8개. 신뢰구간은 날짜 블록 재표집 10,000회(블록 1,279개, seed 42)이며
  블록이 독립이 아니므로 폭은 하한으로 읽는다.
- 반려 원인: 평가 행의 lag 를 기준 시점에 고정하는 규칙이 학습 시 매일 갱신되는 lag 와 어긋난다.

### 예측구간 보정 (목표 미달 — 음성 기록)

- 80% 구간 포함률 목표 0.77~0.83, **8개 기준 시점 중 3개만 통과** → `picp_rejected` 기록.
- 통과: 2025-01-01(0.8064), 2025-10-01(0.8127), 2026-01-01(0.8014)
- 미달: 2024-11-01(0.8588), 2024-12-15(0.8712), 2025-02-13(0.8452), 2025-04-01(0.8357), 2025-07-01(0.8465)
- 달성: 음수 예측 72,806건 → 0건, 구간 교차 0, 조건부 슬라이스 누락 0.
- 원인: 보정 창과 평가 창의 잔차 분포 불일치(교환가능성 위반). 보정기 자기 포함률은 8개 전부 0.80001 로
  분위수 수준·축척 정의는 정상이다. 상세 근거는 `interval_calibration_REPORT.md` §3.
- 달력 피처: 공휴일 MAE 159.95 → 147.81 (7.59% 개선, 목표 15% 미달 → 반려), 비공휴일 90.13 → 82.35 (−8.63%).
- **목표치와 통과 기준은 사후에 변경하지 않았다.** 게이트 대상을 줄이는 대안은 채택하지 않았고,
  시간 감쇠 가중 분위수(반감기 30일)로 1회 재실험했다(아래 절).

### 예측구간 보정 — 시간 감쇠 가중 재실험 (부분 개선, 목표 미달 유지)

- 방법: 보정 잔차에 나이 가중치 2^(−나이/30일)을 주는 가중 분위수. 그룹·축척·창(90일)·게이트 정의는 불변.
- **밴드 안 통과 3개 → 4개**로 늘어 채택했다. 다만 8개 전부 통과 목표는 여전히 미달(`picp_rejected` 유지).
- 통과: 2025-01-01(0.8259), 2025-04-01(0.8036, 신규), 2025-10-01(0.7911), 2026-01-01(0.7917)
- 미달: 2024-11-01(0.8582), 2024-12-15(0.8707), 2025-02-13(0.8535), 2025-07-01(0.8383)
- 폭 중앙값은 8개 중 7개에서 줄었다(합 1910.2 → 1868.7). 평균 |포함률−0.8| 0.0347 → 0.0334.
- 퇴행 없음: 조건부 슬라이스 누락 0, 구간 교차 0, 음수 예측 0, 달력 판정 동일(공휴일 7.59% 개선·반려),
  분산 백테스트 실패 목록 동일(8개). 2025-02-13 은 0.8452 → 0.8535 로 소폭 악화(이미 밴드 밖).
- 가중 자기 포함률은 8개 전부 0.80001, 비가중으로 재면 0.7671~0.8055 → 남은 오차의 원인은
  분위수 구현이 아니라 잔차 분포 이동임이 재확인됐다.
- 구조 한계: 초기 장기 기준 시점(2024-11-01·2024-12-15)은 182-366 지평의 보정 원점이 데이터 시작
  (2024-01-08) 때문에 90일 학습분으로 절단되어 폭이 과대하다. 이 문제의 설계 변경은 별도 승인이 필요하다.
- 상세 비교표와 근거는 `interval_decay_REPORT.md`.
