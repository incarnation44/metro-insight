# 시간 감쇠 가중 분위수 실험 기록 (2026-11-15)

## 1. 목적과 가설

80% 예측구간의 포함률(실제 값이 구간 안에 들어온 비율, 이하 포함률)이 8개 기준 시점 전부에서
0.77~0.83 안에 들어오는지 확인한다.

3차 실행에서 원인은 확정됐다. 보정기를 보정 표본 자신에 적용한 포함률이 8개 기준 시점 전부
0.800 이었으므로 분위수 수준·축척 정의·유한표본 보정은 정상이고, 실제 원인은 보정 창과 평가 창의
잔차 분포 불일치다. 같은 그룹에서 "보정 분위수 ÷ 평가 잔차의 0.8 분위수" 가 최대 3.13배까지 벌어졌다.

가설: 보정 창(90일) 안에서도 오래된 잔차가 최근보다 다른 수준을 담고 있다면, 잔차 나이에 따라
무게를 줄이면 창 편향이 줄어 포함률이 0.8 쪽으로 당겨진다. 반감기 30일이면 30일 전 잔차는 절반,
60일 전은 1/4, 90일 전은 1/8 무게가 된다.

## 2. 방법

- 가중치 w = 2^(−age/30). age = 평가 기준 시점 − 그 잔차가 발생한 날(일 단위). 나이는 행마다
  실제 날짜에서 계산하므로 보정 원점이 절단된 경우에도 어긋나지 않는다.
- 가중 분위수: 점수를 안정 정렬(mergesort)한 뒤 누적 가중 비율이 유한표본 수준
  ceil((n+1)·0.8)/n 을 처음 넘는 점수를 고른다. 같은 점수의 순서가 뒤집혀도, 입력 행 순서를
  섞어도 결과가 같다(결정론).
- 유지한 것: 그룹(지평밴드 4 × 규모 tertile 3 = 12개), 축척 정의(월 프로필 평균, 없으면
  (역, 시간대) 평균), 보정 원점 배치(창 90일), 유한표본 보정, 폴백 규칙, 게이트 정의, 밴드 0.77~0.83.
- 평가 행 집합은 3차와 동일하다. 기준 시점별 평가 행 수가 8개 모두 같고, 통합 6,983,340행도 같다.

  2025-01-01 은 밴드 안이지만 여유가 줄었고, 2025-02-13 은 더 멀어졌다.
- 구간 폭은 8개 중 7개에서 줄었다(합 1910.2 → 1868.7). 폭이 줄어든 만큼 포함률이 떨어진 것은
  아니다. 폭이 줄면서도 포함률이 0.8 쪽으로 올라온 기준 시점이 2025-04-01 하나 있고,
  2025-10-01·2026-01-01 은 폭과 포함률이 함께 낮아져 0.8 에 가까워졌다.
- 3차와 이번의 평균 |포함률 − 0.8| 은 0.0347 → 0.0334 로 조금 줄었다.
- 통합(8개 기준 시점 합산, 6,983,340행): 포함률 0.8392 → 0.8347, 폭 중앙값 245.2 → 239.2.

## 4. 분위수 자체는 여전히 정상인지 (진단)

- 가중 분위수를 보정 표본 자신에 가중 포함률로 적용하면 8개 기준 시점 전부 0.800 이다.
  즉 가중 분위수도 명목 수준을 정확히 구현한다.
- 같은 표본에 비가중 포함률로 재면 0.7671~0.8055 로 흩어진다. 이는 가중 분위수가 무게가 큰
  최근 잔차 쪽에 맞춰졌기 때문이며, 남은 오차의 출처가 분위수 구현이 아니라 잔차 분포 이동임을
  다시 확인해 준다.

## 5. 게이트 판정 (정의 변경 없음)

| 항목 | 기준 | 결과 |
|---|---|---|
| 80% 포함률, 8개 기준 시점 전부 | 0.77~0.83 | **미달 4/8** (밴드 밖: 2024-11-01, 2024-12-15, 2025-02-13, 2025-07-01) |
| 조건부 슬라이스 리포트 | 누락 0 | 충족(필수 6종 + 지평 4종 + 호선 8개, 누락 0) |
| 구간 교차 | 0 | 0 |
| 음수 예측 | 0 | 하한 음수 0건(클램프 전 점예측 음수 72,806건 → 0) |
| 공휴일 MAE −15% 이상 또는 음성 기록 | 15% 이상 또는 기록 | 미달 7.59%, 음성 기록 남김(`rejected`) |
| 비공휴일 악화 | +1% 이내 | 통과(−8.63%, 개선) |
| 분산 백테스트 | (기록 항목) | 8개 기준 시점 전부 실패 — 3차와 같다 |

- 공휴일·비공휴일 값은 구간 폭과 무관한 점예측 비교이므로 3차와 동일하다.
- 여전히 게이트는 미달이다. 포함률 판정은 `picp_rejected=true` 로 남겼고, 밴드 밖 4개 기준 시점과
  두 설계(주 설계·밴드 단위 폴백)의 밴드 밖 목록을 `log.jsonl` 에 기록했다. 수치는 손대지 않았다.

## 6. 채택 판정

**채택** — 기본 보정 경로를 시간 감쇠 가중 분위수로 바꾼다.

근거:
1. 밴드 안 통과 수가 3개 → 4개로 늘었다(목표는 8개, 미달 사실은 그대로).
2. 다른 게이트에 퇴행이 없다. 조건부 슬라이스 누락 0, 구간 교차 0, 음수 0, 달력 비교는 3차와
   같은 값·같은 판정, 분산 백테스트 실패 목록도 동일하다.
3. 구간 폭이 7/8 기준 시점에서 줄었고(합 1910.2 → 1868.7), 평균 편차도 줄었다.
4. 가중 분위수가 자기 표본에서 명목 0.800 을 정확히 재현하므로 구현 결함이 아니다.

채택의 한계(숨기지 않음):
- 2025-02-13 은 0.8452 → 0.8535 로 악화됐다. 반감기 30일이 항상 유리하지는 않다는 뜻이다.
- 포함률이 0.83 을 넘는 기준 시점(2024-11-01·2024-12-15)은 여전히 폭이 과대하다. 이 두 기준 시점의
  평가 행은 전부 182-366 지평이고, 보정 원점이 데이터 시작(2024-01-08) 때문에 90일 학습분으로
  절단된다. 보정 모형과 평가 모형의 학습량 차이라는 구조 문제는 가중으로 해결되지 않는다.
- 따라서 이 실험은 "부분 개선" 이며 목표 달성이 아니다.

## 7. 손질한 결함

- 실행 로그를 열기 전에 이전 로그를 지우던 경로를 없앴다. 이제 같은 디렉터리에 로그가 있으면
  `log-2.jsonl`, `log-3.jsonl` 처럼 비어 있는 이름을 골라 새로 쓴다. 이전 실행의 근거가 사라지지
  않는다. manifest 의 `log.path` 에 실제 파일명을 적는다.


- 평가 데이터(test.csv.gz) 접근 없음(`test_accessed=false`), 접근 가드는 실행 끝에 통과 확인.
